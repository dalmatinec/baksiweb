# Переезд на другой сервер и восстановление после падения

Всё, что нужно для восстановления, лежит в одном архиве бэкапа: база (клиенты, балансы, оплаты, токены ботов
в зашифрованном виде) и данные каждого бота. Плюс файл `.env` с `SECRET_KEY`: без него токены ботов
не расшифровать. **Храните `.env` отдельно от сервера** (менеджер паролей и офлайн-копия).

## Где взять бэкап

- Каждую ночь в 04:00 архив уходит в канал бэкапов (хаб → Админка → 🛟 Надёжность → Канал для бэкапов).
  Большой архив приходит частями `baksi-…zip.001`, `.002`, … Скачайте все части в одну папку.
- Если сервер ещё жив: `data/backups/` (на сервере хранится только последний бэкап).

## Переезд (или сервер умер)

1. **Старый сервер должен быть выключен** (или платформа остановлена: `docker compose stop`). Иначе один
   и тот же бот будет работать на двух серверах, и Telegram будет обрывать обоих (ошибка Conflict).
2. На новом сервере (Ubuntu):
   ```bash
   git clone https://github.com/dalmatinec/baksiweb /opt/baksi && cd /opt/baksi
   # положите сохранённый .env в /opt/baksi/.env (тот же SECRET_KEY!)
   bash deploy/install.sh
   ```
3. Загрузите бэкап на сервер (с компьютера):
   ```bash
   scp baksi-20260101-040000.zip* root@НОВЫЙ_IP:/root/
   ```
4. Восстановите:
   ```bash
   cd /opt/baksi
   bash deploy/restore.sh /root/baksi-20260101-040000.zip        # один файл
   bash deploy/restore.sh /root/baksi-20260101-040000.zip.001    # если частями - первая часть
   ```
5. В DNS домена `baksi.cloud` смените A-запись на новый IP. Пока запись обновляется (до часа, обычно минуты),
   клиентские боты уже работают: им домен не нужен, они сами опрашивают Telegram. Сайт и оплаты
   заработают, как только домен укажет на новый сервер.
6. Проверка: хаб присылает «✅ Baksi Cloud запущен», в веб-админке «Копии ботов» - все зелёные.

Простой: время от выключения старого сервера до шага 4, обычно 15–30 минут.

## Если Telegram заблокировал хаб-бота

Заранее: создайте второго бота в @BotFather и впишите в `.env` строку `HUB_BOT_TOKEN_RESERVE=...`,
для входа на сайте сделайте ему `/setdomain baksi.cloud`. Дальше всё само:

- Telegram три раза подряд отклоняет токен основного бота → платформа переключается на запасной и перезапускается.
- Всем клиентам уходит сообщение о новом боте: через их собственных ботов, от запасного бота (тем, кто его
  открывал) и баннером на сайте.
- Вам приходит инструкция: прописать новые токены в `.env`, чтобы запасной стал основным, и завести новый запасной.

## Если удалили или испортили одного бота клиента

Веб-кабинет → бот → «Бэкап (по желанию)» → восстановить из архива этого бота. Остальные боты не затрагиваются.
