# Baksi Cloud

Платформа, которая продаёт Telegram-ботов по подписке. Клиент выбирает бота, оплачивает срок, вставляет токен из
@BotFather, и через несколько секунд его собственный бот работает. Запуск, перезапуски, лимиты памяти, бэкапы,
продление и смена токена работают без участия администратора.

Что внутри:

- **Хаб-бот**: каталог, покупка, пробный период, мои боты, кошелёк, промокоды, рефералы, вход в веб, админ-команды.
- **Сайт и кабинет** (один и тот же интерфейс работает как Telegram Mini App): боты, оплата, настройки, логи,
  бэкап своего бота.
- **Админка владельца**: выручка, проблемные боты, клиенты и балансы, тарифы, промокоды, платежи, рассылка, бэкапы.
- **Модули-боты**: Link (генератор ссылок), Рассылка (по группам), Экспресс (заявки в группу исполнителей),
  Связь (переписка клиента с исполнителем, когда у клиента спам-блок).

## Установка (Ubuntu + Docker)

```bash
git clone -b platform-v1 https://github.com/dalmatinec/baksiweb /opt/baksi
cd /opt/baksi
bash deploy/install.sh
```

Скрипт спросит токен хаб-бота, ваш Telegram ID, токен Crypto Pay и домен, сам создаст `SECRET_KEY` и запустит
всё в Docker. **Сохраните `SECRET_KEY` отдельно от сервера**: им зашифрованы токены клиентов, и без него токены
из бэкапа не расшифровать.

После запуска:

1. Откройте хаб-бота и нажмите /start: владельцу приходит «✅ Baksi Cloud запущен».
2. Цены уже стоят: $10 за 7 дней, $30 за месяц, $80 за 3 месяца, $150 за полгода, $270 за год, $600 навсегда.
   Поменять: хаб-бот → ⚙️ Админка → 🌐 Веб-админка → Тарифы (или `/app#/admin/catalog`). Тариф без цены не продаётся.
3. По желанию: ссылка на поддержку и процент рефералки в разделе «Настройки» админки.

Управление:

```bash
docker compose logs -f baksi              # логи
docker compose restart baksi              # перезапуск платформы (боты клиентов перезапустятся сами)
bash deploy/update.sh                     # обновление: бэкап → git pull → пересборка
docker compose exec baksi python -m baksi backup   # бэкап вручную
bash deploy/restore.sh data/backups/baksi-YYYYMMDD-HHMMSS.zip   # восстановить всё
```

## Домен, сайт и Mini App

Без домена работает только хаб-бот: покупка, токен, кошелёк, управление ботами. С доменом включаются сайт,
кабинет, Mini App и вход по одноразовой ссылке.

Для теста свой домен не нужен: `install.sh` предложит бесплатный адрес `<IP-сервера>.sslip.io`. Он указывает
на ваш сервер, Caddy выпускает для него настоящий сертификат https, и всё работает как с доменом.

1. Направьте A-запись домена на сервер.
2. В `.env` задайте `DOMAIN=example.com` и `PUBLIC_URL=https://example.com`, затем
   `docker compose --profile https up -d`. Caddy сам получит сертификат.
   Если на сервере уже стоит nginx (порты 80/443 заняты), Caddy не нужен: задайте только `PUBLIC_URL` и выполните
   `bash deploy/nginx-setup.sh`. Скрипт добавит отдельный сайт в nginx и выпустит сертификат certbot'ом, остальные
   сайты не затрагиваются.
3. Кнопка «Открыть» в хаб-боте (Mini App) настраивается автоматически при запуске.
4. Вход на сайте через Telegram-виджет (по желанию): @BotFather → /setdomain → ваш домен, затем включите
   «Вход через Telegram-виджет» в настройках админки.

## Оплата через CryptoBot

1. @CryptoBot → Crypto Pay → Create App, токен вписать в `CRYPTOPAY_TOKEN`.
2. Этого достаточно: платформа сама проверяет неоплаченные счета каждые 15 секунд.
3. Для мгновенного зачисления включите вебхук: Crypto Pay → ваше приложение → Webhooks →
   `https://ваш-домен/api/cryptopay/webhook` (подпись проверяется).

Деньги в платформе хранятся в центах USD на балансе клиента. Каждое движение денег записывается в журнал операций.
Если клиент пополнял ради конкретной покупки, бот оплачивается сразу после зачисления.

## Как это работает

```
baksi/                  платформа (один процесс)
  supervisor.py         копии ботов: запуск, перезапуски, лимит памяти, логи, проверка токена
  billing.py            баланс, покупки, продления, пробный период, промокоды, рефералка
  instances.py          токен, настройки, пауза, удаление, события от ботов
  hub/                  хаб-бот (aiogram)
  web/                  FastAPI + сайт/кабинет/Mini App/админка (static/, без сборки)
  cryptopay.py, backup.py, jobs.py, notify.py
modules/
  kit/                  общее для модулей: /bind, события платформе, кнопки с цветом и премиум-эмодзи
  link/ rassylka/ express/ svyaz/   боты (каждый с manifest.json)
```

Каждая копия бота - отдельный процесс со своим токеном и своей папкой `data/instances/<id>`.

- **Перезапуски.** Супервизор раз в 5 секунд сверяет, что должно работать (оплачено, есть токен, не на паузе), с тем,
  что работает. Упавший бот перезапускается с паузой 2 с, 4 с, … 5 мин.
- **Цикл падений.** 5 падений за 10 минут - статус «Сбой», клиенту и вам уходит уведомление с последними строками
  лога, повтор через 10 минут.
- **Память.** Если процесс превысил лимит модуля (`mem_mb` в манифесте), он перезапускается, а вам приходит
  уведомление. Общий потолок памяти задаёт `mem_limit` контейнера (`MEM_LIMIT`, по умолчанию 3g). Копии работают
  с пониженным приоритетом, чтобы хаб и сайт оставались отзывчивыми.
- **Отозванный токен.** Если Telegram отклонил токен, бот не перезапускается в цикле. Клиент получает «вставьте
  новый токен» и меняет его сам в боте или кабинете. Данные и настройки сохраняются.
- **Подписка.** Когда срок кончается, платформа продлевает подписку с баланса (если включено автопродление и хватает
  денег) или останавливает бота. Напоминания приходят за 3 дня и за 1 день. Данные истёкшего бота хранятся
  `PURGE_AFTER_DAYS` дней, потом архивируются в `data/backups/purged` и удаляются.
- **Бэкапы.** Каждую ночь в 04:00 (по `TZ`) делается архив: база платформы и данные всех ботов. Базы SQLite
  копируются целостно, без остановки. Хранится `BACKUP_KEEP_DAYS` дней, архив до 45 МБ присылается вам в Telegram.
  Клиент может скачать и восстановить бэкап своего бота в кабинете.

## Безопасность

- Токены клиентов зашифрованы (Fernet, ключ из `SECRET_KEY`), в логах вырезаются.
- Вход без паролей и телефонов:
  - одноразовая ссылка из хаб-бота, живёт 10 минут;
  - подпись Telegram Mini App;
  - Telegram Login Widget.
- Сессии хранятся в базе только хешами. Есть «выйти везде».
- Защита API:
  - от CSRF: обязательный заголовок `X-Baksi` + SameSite-cookie;
  - лимиты запросов по IP;
  - ограничение размера запросов;
  - CSP и защитные заголовки.
- Хаб-бот защищён антифлудом. Забаненный клиент теряет доступ, его боты замораживаются.
- Вебхук CryptoBot проверяется по подписи. Зачисление идемпотентно: повтор не начислит дважды.

## Оформление ботов

Веб-админка → «Оформление». Для хаб-бота и каждого типа ботов клиентов можно поменять:

- тексты (HTML, подстановки вроде `{имя}`, премиум-эмодзи `<tg-emoji emoji-id="ID">😀</tg-emoji>`);
- кнопки: подпись, цвет, премиум-иконку;
- раскладку: сколько кнопок в ряд.

Справа живое превью. Изменения доходят до всех ботов этого типа за несколько секунд, без перезапуска. Собственные
правки клиента в `/admin` его бота важнее, настройки владельца работают как значения по умолчанию.

Премиум-эмодзи удобнее ставить прямо в Telegram: хаб-бот → ⚙️ Админка → 🎨 Оформление. Тексты просто присылаете
сообщением (форматирование и премиум-эмодзи сохраняются), у кнопки премиум-эмодзи в начале подписи становится иконкой.
Веб-админка показывает премиум-эмодзи в превью картинками (миниатюры стикеров через Bot API). Премиум-иконки Telegram
показывает, если Premium есть у владельца конкретного бота (у хаб-бота - у вас, у ботов клиентов - у клиента).

Чтобы модуль поддерживал оформление, опишите в `manifest.json` блок `ui` (screens, texts, buttons, layout) и берите
значения через `baksi_kit.ui_text()`, `ui_btn()`, `ui_cols()`.

## Новый бот в каталоге

Перед добавлением пройдите чек-лист [docs/MODULE_RULES.md](docs/MODULE_RULES.md): там правила и журнал найденных ошибок,
чтобы они не повторялись в новых модулях.

Создайте папку `modules/<slug>/` с кодом бота и `manifest.json`:

```json
{
  "slug": "mybot", "title": "Мой бот", "tagline": "коротко", "description": "Что делает",
  "entry": "bot",           // пакет bot/ (python -m bot) или файл main.py ("main")
  "color": "#C6F24E", "mem_mb": 150, "sort": 50,
  "needs_bind": true,       // нужна ли привязка группы командой /bind
  "bind_hint": "Добавьте бота в группу и отправьте:",
  "how": ["шаг 1", "шаг 2"], "features": ["…"],
  "settings": [{"key": "all_admins", "type": "bool", "label": "…", "default": false}],
  "default_plans": [7, 30, 90, 180, 365, 0],
  "bot_change_hint": "Что сделать клиенту, если он подключил другого бота (добавить в группы и т.п.)"
}
```

Перезапустите платформу: бот появится в админке, и после того как вы зададите цену, его можно будет продавать.

Платформа передаёт копии бота переменные:

- `BOT_TOKEN`;
- `OWNER_IDS` (клиент и его дополнительные админы);
- `DATA_DIR` (папка для базы);
- `BAKSI_PLATFORM_FILE` (настройки из кабинета, код привязки);
- `PROXY_URL`.

Из `modules/kit/baksi_kit.py` доступны:

- `bind_router()` - команда /bind и отслеживание удаления бота из группы;
- `ready(bot)` - сообщить платформе, что бот запущен;
- `notify(text)` - написать владельцу бота в хаб;
- `setting(key)` - настройки из кабинета;
- `btn()`/`kb()` - кнопки с цветом (`primary`/`success`/`danger`) и премиум-иконкой. Если у владельца токена нет
  Premium, Telegram просто не покажет иконку.

Все модули работают и сами по себе, без платформы, как обычный бот с `.env`.

## Модули

- **Link** - перенос `newlink`. Добавлено:
  - кнопка двигается прямо в своей карточке: видно всё меню, стрелки ⬅️⬆️⬇️➡️ двигают её на один шаг, меню
    у пользователей меняется сразу, нажатие на другую кнопку переходит к ней;
  - админка разложена по категориям: Контент, Продвижение, Люди и чаты, Система.
- **Рассылка** - перенос `rassylka`. Админская группа привязывается командой `/bind <код>` из кабинета, а не через
  `.env`. Режим «все участники админской группы» и дополнительные админы включаются в кабинете.
- **Экспресс** - новый.
  - Заказчик пишет боту, заявка уходит форвардом в группу исполнителей, ответ реплаем уходит заказчику.
  - Под заявкой кнопки «Закрыть» и «Бан».
  - Антиспам, анонимные ответы, статистика исполнителей.
- **Связь** - новый.
  - Отделы и исполнители по ссылке-приглашению.
  - Исполнитель жмёт «Ответить» и пишет без реплаев.
  - Передача диалога в другой отдел, режим «темы» в группе с форумом.

## Тесты

```bash
pip install -r requirements.txt
python -m unittest discover -s tests          # платформа, хаб-бот, Экспресс, Связь, подписи
cd modules/link && python -m unittest         # Link на фейковом Telegram
```
